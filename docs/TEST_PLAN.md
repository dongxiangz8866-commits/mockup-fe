# 样机系统效果测试计划

## 1. 测试目标

本轮测试目标不是验证代码覆盖率，而是验证样机效果是否“像真实印在衣服上”，并找出不同输入变量下最容易失败的组合。

重点判断 5 件事：

1. 图案是否贴在正确的衣服区域，而不是漂浮或跑偏。
2. 图案是否跟随身体姿态、衣服曲面和褶皱产生合理变形。
3. 图案是否继承原照片的光影、布料纹理和环境色。
4. 在不同衣服颜色和图案颜色组合下，图案是否仍清晰可读。
5. 头发、手臂、项链等前景遮挡是否能盖住图案。

当前唯一测试对象：

- `/displace`：真人照片 + 深度/位移 + 光照合成链路。

## 2. 测试维度

### 2.1 衣服颜色

衣服颜色是最高优先级维度，因为它直接影响光照融合、图案可读性和黑位抬升策略。

| 编号 | 类别 | 示例 | 重点风险 |
|---|---|---|---|
| C1 | 白色 / 浅灰 | 白 T、浅灰卫衣 | 褶皱太弱、图案像浮在表面、白底图案边界不自然 |
| C2 | 黑色 / 深灰 | 黑 T、深灰卫衣 | 暗色图案消失、图案被阴影压成黑块 |
| C3 | 深色彩衫 | 深蓝、深绿、深紫、酒红 | 走错颜色 preset、复杂图案暗部融合到衣服里 |
| C4 | 中亮度彩衫 | 红、蓝、绿、黄、卡其 | 图案色偏、衣服底色污染过强或过弱 |
| C5 | 高饱和亮色 | 亮黄、荧光绿、亮粉 | 图案颜色失真、光照层过度洗色 |

### 2.2 模特姿势

姿势决定 pose quad 是否稳定，也决定图案是否需要更强曲面包裹。

| 编号 | 类别 | 示例 | 重点风险 |
|---|---|---|---|
| P1 | 正面站立 | 肩膀水平、胸口完整可见 | 基准效果 |
| P2 | 轻微侧身 | 身体 15-30 度旋转 | 图案透视不足、左右宽度不自然 |
| P3 | 大幅侧身 | 身体 45 度以上 | pose quad 错位、图案压到身体外 |
| P4 | 手臂遮挡胸前 | 手臂、手掌覆盖衣服 | 前景遮挡失败，图案画到手上 |
| P5 | 头发遮挡衣服 | 长发落在胸口 | hair mask 边缘漏印 |
| P6 | 坐姿 / 弯腰 | 躯干压缩、衣服堆叠 | quad 位置和褶皱方向不匹配 |

### 2.3 衣服褶皱程度

褶皱程度用于验证位移、light map、shading map 是否能产生真实贴合感。

| 编号 | 类别 | 示例 | 重点风险 |
|---|---|---|---|
| W1 | 平整 | 新衣、棚拍正面 | 缺少真实褶皱，图案像贴纸 |
| W2 | 轻微褶皱 | 日常穿着 | 基准效果 |
| W3 | 明显纵向褶皱 | 胸口、腹部有竖向折痕 | 图案应随折痕轻微弯曲和变暗 |
| W4 | 大面积软折 | 宽松卫衣、松垮 T 恤 | 只靠窄频 shading 可能看不到软折 |
| W5 | 局部强阴影 | 腋下、胸口被头发/手投影 | 阴影可能被误当布料褶皱，压黑图案 |

### 2.4 图案种类

不同图案对真实感问题的敏感点不一样，必须分层测试。

| 编号 | 类别 | 示例 | 重点风险 |
|---|---|---|---|
| A1 | 大块文字 | 黑字、白字、品牌 slogan | 文字变形过强、边缘锯齿、可读性下降 |
| A2 | 小字 / 多行字 | 成分表、长句、细字体 | 缩放后模糊、褶皱导致不可读 |
| A3 | 简单图标 | logo、几何图形 | 边缘是否贴合，透明边是否干净 |
| A4 | 卡通插画 | 猫、人物、IP 风格图 | 暗部糊成块、内部透明边产生脏边 |
| A5 | 照片类图案 | 人像、风景、渐变图 | 色偏、暗部层次、光照叠加是否自然 |
| A6 | 低透明度 / 烟雾 | 半透明阴影、发光、烟雾 | alpha 区域在深色衣服上不可见 |
| A7 | 全幅图案 | 覆盖大部分印花板 | 边缘是否被衣服/遮挡正确裁切 |

### 2.5 图案颜色

图案颜色需要和衣服颜色交叉测试，尤其是低对比组合。

| 编号 | 类别 | 示例 | 重点风险 |
|---|---|---|---|
| K1 | 纯黑 / 近黑 | #000、深灰 | 黑衫上不可见，白衫上过度吃阴影 |
| K2 | 纯白 / 近白 | #fff、浅灰 | 白衫上边界消失，黑衫上过亮像贴纸 |
| K3 | 高饱和色 | 红、蓝、黄、绿 | 光照叠加后偏色或过度降饱和 |
| K4 | 多色复杂 | 彩色插画 | 不同颜色区域受光照不一致 |
| K5 | 渐变 / 半透明 | 透明 PNG、发光边 | alpha 边缘脏边，深色衣服上细节丢失 |

### 2.6 补充维度

以下维度不一定第一轮全量覆盖，但要在问题定位时保留。

| 编号 | 类别 | 示例 | 重点风险 |
|---|---|---|---|
| S1 | 图案位置 | 胸口居中、偏左、靠近领口、靠近下摆 | 位置越靠边，曲面/遮挡越容易错 |
| S2 | 图案尺寸 | 小 logo、中等胸标、大面积印花 | 大尺寸更容易暴露透视和身体包裹问题 |
| S3 | 原图光照 | 棚拍、侧光、逆光、室外暖光 | 环境色融合、阴影误判 |
| S4 | 衣服材质 | 棉 T、卫衣、亮面/针织 | 布料纹理强度是否匹配 |
| S5 | 图案分辨率 | 低清 300px、高清 2K、透明 PNG | 模糊、锯齿、DPI 不足 |
| S6 | 原衣已有图案 | 纯色、已有 logo、花纹衣 | 原图案可能干扰 garment sample 和遮挡判断 |

## 3. 测试分层

### 3.1 第一层：基准冒烟测试

目的：快速确认主链路可用。

建议每次改动后都跑：

| 用例 | 衣服 | 姿势 | 褶皱 | 图案 | 期望 |
|---|---|---|---|---|---|
| B01 | 白色 | 正面 | 轻微 | 黑色大字 | 文字清晰，光影自然 |
| B02 | 黑色 | 正面 | 轻微 | 白色大字 | 不过亮，不像浮贴纸 |
| B03 | 深色彩衫 | 正面 | 明显 | 彩色卡通 | 暗部不糊，图案可读 |
| B04 | 红/蓝彩衫 | 正面 | 明显 | 黑白 logo | 不明显偏色 |
| B05 | 白色 | 头发遮挡 | 轻微 | 彩色插画 | 头发盖住图案，不漏印 |

### 3.2 第二层：变量矩阵测试

第一轮不建议做 5 个维度的全组合，数量会爆炸。建议用“代表组合”覆盖主要风险。

| 组 | 主要验证点 | 衣服颜色 | 姿势 | 褶皱 | 图案类型 | 图案颜色 |
|---|---|---|---|---|---|---|
| M01 | 白衫基准 | C1 | P1 | W2 | A1 | K1 |
| M02 | 黑衫可见性 | C2 | P1 | W2 | A4 | K4 |
| M03 | 深色彩衫 | C3 | P1 | W3 | A4 | K4 |
| M04 | 中亮彩衫色偏 | C4 | P1 | W3 | A5 | K4 |
| M05 | 文字可读性 | C1/C2 | P1 | W3 | A2 | K1/K2 |
| M06 | 大面积印花 | C1/C4 | P2 | W4 | A7 | K4 |
| M07 | 侧身透视 | C1/C2 | P2/P3 | W2 | A3 | K3 |
| M08 | 手臂遮挡 | C1/C4 | P4 | W2 | A1/A4 | K4 |
| M09 | 头发遮挡 | C1/C2 | P5 | W2 | A4 | K4 |
| M10 | 半透明图案 | C2/C3 | P1 | W3 | A6 | K5 |
| M11 | 平整衣服兜底 | C1/C2 | P1 | W1 | A3 | K3 |
| M12 | 强阴影误判 | C1/C4 | P5/P6 | W5 | A4 | K4 |

### 3.3 第三层：回归测试

只要改动以下模块，就必须跑回归：

- pose quad 计算
- depth / displace / light / shading map 生成
- garment color sample / scene sample
- hair mask / foreground occlusion
- shader 中的 brightness、lift、tint、lightStrength、depthWrap
- cache version

回归重点：

1. 白衫效果不应被深色衫修复牵连。
2. 黑衫/深色彩衫上暗色复杂图案不应重新变成黑斑。
3. 头发和手部遮挡不能退化。
4. 调整图案大小和位置时，不应重新采样错误的衣服颜色。
5. 缓存命中和清缓存重算的结果应一致。

## 4. 测试素材准备

### 4.1 模特照片

第一轮建议至少准备 18 张：

| 类别 | 数量 | 说明 |
|---|---:|---|
| 白/浅色衣服 | 3 | 正面、轻侧、头发遮挡 |
| 黑/深灰衣服 | 3 | 平整、轻褶皱、明显褶皱 |
| 深色彩衫 | 4 | 深蓝、深绿、深紫、酒红 |
| 中亮彩衫 | 4 | 红、蓝、绿、黄/卡其 |
| 特殊姿势 | 4 | 手臂遮挡、坐姿、侧身、弯腰 |

每张照片需要记录：

- 衣服颜色类别
- 姿势类别
- 褶皱类别
- 是否有头发/手臂/饰品遮挡
- 原图尺寸
- 是否已有衣服图案

### 4.2 图案素材

第一轮建议至少准备 12 张 PNG：

| 类别 | 数量 | 说明 |
|---|---:|---|
| 大字 | 2 | 黑字、白字 |
| 小字 | 2 | 黑字、白字，含细线字体 |
| 简单 logo | 2 | 单色、彩色 |
| 卡通插画 | 2 | 一个明亮、一个暗部较多 |
| 照片/渐变 | 2 | 人像或风景、渐变色块 |
| 半透明图案 | 2 | 烟雾、发光、阴影边 |

每张图案需要记录：

- 是否透明 PNG
- 主色
- 明暗分布
- 细节密度
- 原始分辨率

## 5. 评估标准

每个测试结果按 1-5 分评价，3 分为可接受，4 分为可用于 MVP 展示，5 分为接近商业样机质量。

| 指标 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 位置准确 | 明显跑偏 | 大致在胸口区域 | 精准落在衣服可印区域 |
| 形变贴合 | 完全平贴 | 有基本透视/包裹感 | 能跟随身体曲面和褶皱 |
| 光影融合 | 像贴纸 | 亮暗基本匹配 | 继承原图光照和布料层次 |
| 颜色可信 | 明显偏色/脏色 | 可接受轻微偏色 | 像真实油墨印在该颜色布料上 |
| 图案可读性 | 看不清 | 主体可读 | 文字和插画细节清楚 |
| 遮挡处理 | 画到头发/手上 | 大体遮挡正确 | 边缘自然，无明显漏印 |
| 边缘质量 | 锯齿/白边/黑边 | 边缘基本干净 | 边缘融入布料，无脏边 |

判定规则：

- 单项 1 分：必须记录为问题。
- 总分低于 21/35：不可用于展示。
- 总分 21-27/35：可作为技术验证，但需要标注限制。
- 总分 28+/35：可进入 MVP 展示素材池。

## 6. 测试流程

### 6.1 手动测试流程

1. 打开 `/displace`。
2. 选择模特照片。
3. 等待状态进入 ready。
4. 上传测试图案。
5. 测试 3 个尺寸：小 logo、中等胸标、大面积印花。
6. 测试 3 个位置：居中、偏左/偏右、靠近领口或下摆。
7. 分别查看合成、位移、光照、Shading 调试视图。
8. 记录评分、截图和问题描述。

每个问题描述至少包含：

- 模特照片文件名
- 图案文件名
- 图案位置和大小
- 当前滑杆值
- 问题现象
- 预期结果
- 截图路径

### 6.2 自动截图流程

当前已有脚本：

```bash
cd app
pnpm screenshot:displace
```

建议用途：

- `pnpm screenshot:displace`：跑 `/displace` 单页截图，适合对比 shader 改动。

后续可以补充一个 `/displace` 专用测试脚本，自动遍历“模特照片 × 图案素材 × 默认滑杆值”，输出到 `app/screenshots/effect-matrix/`。

## 7. 首轮测试优先级

按 ROI 排序：

1. 黑衫 / 深色彩衫 + 暗部复杂卡通图案。
2. 白衫 + 黑色文字，确认白衫基准不退化。
3. 头发遮挡 + 彩色图案，确认 occlusion 能用。
4. 中亮彩衫 + 多色图案，观察是否需要新增 middle-tone preset。
5. 侧身 / 坐姿，验证 pose quad 和 depthWrap 的极限。
6. 半透明图案，确认是否需要 alpha-aware lift。

## 8. 已知风险与对应观察点

| 风险 | 观察点 | 可能动作 |
|---|---|---|
| 深色衣服上暗图案不可见 | 黑衫 + 暗部插画 | 调整 lift / sceneBrightness / black preset |
| 中亮彩衫颜色不稳定 | 卡其、亮黄、红衫 | 增加 middle-tone preset |
| 平整衣服缺少贴合感 | W1 平整照片 | 增加程序生成褶皱或预烤织物层 |
| 头发边缘漏印 | 长发遮挡胸口 | 调整 hair mask dilation / occlusion mask |
| 手臂误印 | 手臂挡胸 | 引入人体/皮肤遮挡 mask |
| 侧身图案不贴合 | P2/P3 侧身 | 改 pose quad 或引入透视/mesh warp |
| 半透明图案偏脏 | 烟雾、发光边 | alpha-aware lift 和边缘处理 |
| 缓存导致结果不一致 | 清缓存前后截图对比 | bump cache version 或修正 cache key |

## 9. 本轮交付物

第一轮测试完成后应输出：

1. 一张测试矩阵表，包含每个用例的 7 项评分。
2. 每个失败用例的截图和复现参数。
3. 按优先级排序的问题清单。
4. 可用于演示的素材白名单。
5. 下一轮算法调参建议。
